How it works

Three layers between raw web data and a sales action

Most tools call an API and display the result. AlphaSignal correlates signals across sources before any AI is involved — so the model writes from evidence, not guesses.

1
Signal Detection — 7 parallel detectors
Every hour, seven independent detectors probe each watched company using the right Bright Data product for that target. LinkedIn Jobs needs a browser that executes JavaScript. G2 and SEC EDGAR need CAPTCHA bypass. Pricing pages need diff-capable scraping. Each detector returns a normalized signal object with value, delta, confidence, and evidence URL.
// normalized signal output
{ type: "hiring_velocity", delta: +180, confidence: 0.91, evidence: "linkedin.com/jobs/..." }
{ type: "funding_detected", value: 80e6, stage: "Series D", confidence: 0.97 }
{ type: "pricing_change", delta: -15, tier: "enterprise", confidence: 0.88 }
2
Signal Correlation — 5 cross-signal thesis rules
Raw signals are meaningless alone. A company posting 20 jobs could be growing or backfilling after layoffs. The correlator tests five thesis patterns that require multiple signals to agree before anything fires. A company hiring fast AND just funded AND getting positive press is a real growth signal. Any one of those alone is noise.
growth_thesis = funding_detected AND hiring_velocity > +50% AND news_positive
competitive_threat = competitor_pricing_dropped AND their_hiring_accelerated
financial_distress = sec_filing_negative AND hiring_freeze AND traffic_declining
supplier_risk = supply_disruption AND pricing_change_imminent
market_disruption = news_score < -0.6 AND traffic_delta < -30%
3
Alert Generation — AI/ML API writes from evidence
Only thesis-matched signals reach the AI/ML API. The prompt includes which thesis fired, all supporting signal values, historical context, and specific evidence URLs. The model doesn't decide what's significant — the correlator already did. It writes the investment narrative: what happened, why it matters, what move to make, what to watch next. No thesis match = no alert — which is why alerts don't hallucinate.

Data infrastructure

Five Bright Data products, each chosen for a reason

This isn't "use whichever API is cheapest." Every product is deployed because the alternative fails on that specific target site.

🔌
MCP Server
Company blogs, LinkedIn profiles, Crunchbase. The scrape_as_markdown tool returns clean structured text — directly usable as model context.
→ Used in: brand analysis, context fetching
🔍
SERP API
Lead discovery runs 8 Google queries per pipeline execution. Raw scraping at this frequency gets rate-limited in minutes. SERP API provides stable, structured results at scale.
→ Used in: lead discovery, funding, news, intent
🕷️
Web Scraper API
Pricing pages. The scraper caches a baseline and diffs it against fresh scrapes — that's how PricingChangeDetector works. A 10% enterprise price drop is a high-confidence signal.
→ Used in: pricing change detector, traffic
🌐
Scraping Browser
LinkedIn job listings are JS-rendered. A static scraper returns empty divs. The Scraping Browser executes the JavaScript and returns the populated DOM with real hiring counts.
→ Used in: hiring velocity detector
🔓
Web Unlocker
G2 (CAPTCHA + bot detection), Glassdoor (geo-gated), SEC EDGAR (blocks non-US IPs). Three different protection models — Web Unlocker handles all three.
→ Used in: intent signals, SEC filings
